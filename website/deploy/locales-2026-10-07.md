# Six-language website — 2026-10-07

English is the default at `https://kissopen.com/`. Other canonical routes:

- Simplified Chinese: `/zh-cn/`.
- Traditional Chinese: `/zh-tw/`.
- Japanese: `/ja/`.
- Korean: `/ko/`.
- Russian: `/ru/`.

The old `/en/` route still serves English, with `/` as its canonical URL.
Language selection lives only in the footer, as an accessible native dropdown.
Switching preserves the current section hash and the existing appearance/motion
preferences. Without JavaScript, the footer offers language links. All main
copy, interactive state text, dialog copy, navigation labels and appearance
labels are translated. Each page publishes six hreflang alternatives and the
English x-default; the sitemap contains the six canonical language routes.
