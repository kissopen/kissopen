# KissOpen 0.3.0

## 中文

KissOpen 首个 macOS 正式桌面版，支持 Apple 芯片和 Intel。

- 本地 Agent、自定义模型服务商与模型选择。
- 项目对话与文件资料库、自定义主题。
- 本地插件管理和分钟级定时任务。
- 独立账号登录及桌面／移动端设备连接。
- 独立桌面更新通道；下载后由你决定何时安装。

模型推理由你配置的服务商提供，工具执行、插件和定时任务由本地 Agent 管理。定时任务需要电脑和本地 Agent 保持运行。

本次发布 macOS 桌面安装包。源码见 [GitHub](https://github.com/kissopen/kissopen)，手机端公开下载仍在准备。

## English

The first stable KissOpen desktop release for Apple Silicon and Intel Macs.

- A local Agent, custom model providers and model selection.
- Project conversations, a file library and custom themes.
- Local plugins and minute-level scheduled tasks.
- Independent account sign-in and desktop/mobile device connectivity.
- An independent desktop update feed; you choose when to install downloaded updates.

Inference uses your configured model provider. Your local Agent manages tool execution, plugins and scheduled tasks. Scheduled tasks require your computer and local Agent to remain running.

This release distributes macOS desktop installers. Source is available on [GitHub](https://github.com/kissopen/kissopen); public mobile downloads are still being prepared.

Desktop: 0.3.0. Bundled Agent: 0.4.71-preview.8 (pinned component, not a separate Agent release).
