# Attribution and distribution

KissOpen's desktop client is derived from Happy Desktop, and its mobile/web
client and encrypted transport are derived from Happy Coder. Their original
MIT copyright notices are retained in `kissopen-desktop/LICENSE` and
`kissopen/LICENSE`. These notices must accompany redistributed derivatives.

KissOpen additions use the root MIT license. Third-party dependencies, fonts,
icons, vendored libraries and generated SDK archives retain their own licenses;
the root license does not replace those licenses. See the package-level
licenses and `kissopen/docs/3dparty.md`.

The official KissOpen brand assets are in `brand/`. This source snapshot does
not include private signing keys, account credentials, user workspaces, plugin
catalog archives, or commercial repository history. Legacy commercial server
and CLI reference copies are excluded from Git. The maintained server and
Agent are published separately:

- https://github.com/kissopen/kissopen-server
- https://github.com/kissopen/kissopen-agent

Third-party plugin packages are not automatically licensed by this repository.
Check each plugin's license before redistribution.
