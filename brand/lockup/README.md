# KISSOPEN 横排 / 竖排锁定

按 `KISSOPEN-VI.html`「04 锁定形式」的规范数值生成：标志几何与 `assets/svg/` 完全同源，字标为 **Chakra Petch 600 转曲路径**（不依赖字体文件，任何环境都不会走形）。

## 构造规则（可复算）

全部按**墨迹外缘**计量（与 `assets/README.md` 一致）：

| | 横排（默认用法） | 竖排（窄版面、印品） |
| --- | --- | --- |
| 标志 | 画布 38 单位，墨迹 21.97 × 20.78 | 画布 44 单位，墨迹 25.44 × 24.06 |
| 标志与字标间距 | 14 单位（墨迹外缘至 "K" 墨迹左缘） | 14 单位（标志墨迹下缘至字标大写高度上缘） |
| 字标 | Chakra Petch 600 · 25 单位 · 字距 0.14em · 全大写 | Chakra Petch 600 · 19 单位 · 字距 0.18em · 全大写 |
| 垂直关系 | 标志墨迹垂直中心 = 字标大写高度中线 | 标志水平居中，字标居中于同一轴线 |
| 最小使用宽度 | **96px**（再小只用单标志） | **96px** |
| 安全边距 | 四周 ≥ 标志墨迹高度的 1/2 | 同左 |

> 与 VI 页的唯一差别：VI 页用 CSS 弹性布局排版，此处按墨迹外缘重新定距，因此间距以墨迹为准、不含字体自带的边距。视觉比例（标志与字标的大小关系、字距、对齐）与 VI 页一致。

## 文件

- `svg/` — 12 份：横排 × 6 色版、竖排 × 6 色版（矢量，`viewBox` 即墨迹外框）
- `png/` — 横排 `primary` / `inverse` / `mono-light` 各 96 / 192 / 384 / 768 / 1536 宽；竖排同三色版各 96 / 192 / 384 / 768 宽

## 使用

```html
<!-- 深底：横排主锁定 -->
<img src="assets/lockup/svg/kissopen-lockup-horizontal-primary.svg" alt="KISSOPEN" height="40">
```

- 只缩放**整体**，不单独拉伸标志或字标；不做描边、阴影、渐变、双色以外的改动。
- 单色场合整词同色（用 `mono-*`）；`primary` 的 KISS/OPEN 双色是唯一的双色用法。
- 宽度小于 96px 时改用单标志（`assets/icon/mark-*`），不要硬缩锁定。
