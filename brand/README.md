# KissOpen brand assets

Vendored from the supplied `modeloc/design/assets` delivery on 2026-10-05.
The original SVG outlines, platform icons and VI documentation are preserved.
No commercial WorPar artwork is used by the open-source UI.

- Display name: **KissOpen**, in every language.
- Lockup: the supplied outlined Chakra Petch wordmark, never live UI text.
- Palette and geometry: see [VI](VI.md).
- macOS, Windows, iOS, Android and web artwork: see [platform guide](icon/README.md).
- Loading: see [motion guide](motion/README.md). Reduced motion stays static.

Desktop assets are regenerated by `pnpm desktop:assets` from this directory,
without depending on the designer's local filesystem. Identifiers, data paths
and protocol names stay unchanged; this is a visual branding update.
